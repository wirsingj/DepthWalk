What this comparison establishes

White and pink textures use the same depth, visibility rules and input contrast. Pink texture includes broader features to help the eyes find a match. This is a candidate, not a proven improvement. The original v0.5 renderer is preserved separately.

The image stays at its chosen size without automatic scaling. Reduce image width if it does not fit. Dot separation is measured in image pixels; keep browser zoom at 100%. Lower image widths also reduce scene detail.

Switching treatments pauses at the same scene frame. Motion renders complete new frames; there is no blending, source-color tint, added outline or accumulated image history.
